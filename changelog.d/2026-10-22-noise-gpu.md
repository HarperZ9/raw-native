- **Noise module on the GPU** (`src/renderer/gpu/shaders/noise.wgsl`, `raw_native_cli noise-parity`).
  The sixteen noise functions run as a compute pass on D3D12, Vulkan and WebGPU, written to
  mirror the CPU module operation for operation. WARP matches the CPU bit for bit, lavapipe to
  6e-8 and an RTX 4090 to 3e-6.
