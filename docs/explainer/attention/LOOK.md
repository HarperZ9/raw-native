# Look target for "How attention moves information", v2 (2026-10-16)

v1 was honest and inspectable but visually thin: most frames were a near-black field with one
row of small mono characters and a small card, the million-point cloud was on screen briefly
and small, and the captions carried the story. v2 keeps every number real and inspectable and
changes the picture.

1. **The data is the subject, at full frame.** Each beat's main mark fills at least half the
   frame: the 1,048,576-point residual cloud; the 64 characters set large across the width;
   attention as arcs up to half the frame tall; the attention matrix as a 900 px field of glowing
   points sized by weight; next-character probability as 63 luminous columns that rise in the
   repeat and collapse when a head is switched off.
2. **Depth.** The cloud is 16 slabs of 16 sequences each, spaced in z, and the camera dollies
   through them in perspective. The atmosphere, the data and the type sit on separate parallax
   planes.
3. **Colour in the art, not the UI.** A full spectral gradient atmosphere (deep blue to violet to
   ember) and a warm-to-white value ramp on the data marks. Type stays ink; the verdict colours
   mark only the numbers that carry a verdict.
4. **Every caption line is a visual beat.** A line on screen always has a picture that shows it:
   "moves each character forward" shows arcs of length one lighting in sequence; "switch it off"
   shows the columns falling.
5. **Unchanged:** every number read from the data bundle and checked by hash at load, the
   interactive inspection, reduced motion as cuts, captions from the script rows.

Done means a side-by-side of v1, v2 and the reference at matching beats, with a beat-by-beat
verdict recorded in `C:/dev/mission-control/2026-10-15-explainer-kit/COMPARE.md`.
